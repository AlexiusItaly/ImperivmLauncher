# English

![Avrora - English](images/Avrora_v1.0.0_EN.png)

## About
**Avrora** is the ultimate evolution of the historical *Imperivm Launcher*. Built entirely on a next-generation, high-performance architecture, it is designed to run *Imperivm: Great Battles of Rome* flawlessly on modern operating systems. Avrora acts as your central hub: it fixes legacy crashes, manages multiplayer routing, integrates your music, and provides a secure, 1-click environment for all community mods and campaigns.

*This project is an unofficial community tool and does not claim ownership of Imperivm or any related intellectual property.*

## System Requirements
* **OS:** Windows 7 (32-bit) or higher.
* **Game:** A valid installation of *Imperivm: Great Battles of Rome*.

## Setup & Instructions
**No more moving files around manually!**
1. Download the latest `AVRORA.exe` release from the button at the top of this page.
2. Run the executable from anywhere on your PC (Desktop, Downloads, etc.).
3. Avrora will automatically detect your game directory if the **Steam version** is installed. If not, you can simply select the folder manually through the app—no need to place the executable inside the game folder!

## Main Features

**1. Core Architecture, Patching & Customization**
* **Next-Gen Engine & UI:** Built for incredibly low memory consumption and lightning-fast execution. Features a completely redesigned layout with dynamic backgrounds and fluid animations.
* **Native DPI Management:** Automatically bypasses Windows display scaling to prevent blurry UI elements on modern high-resolution displays.
* **1-Click Game Optimization:** Instantly applies the **4GB RAM Patch** (preventing crashes during massive sieges), injects legacy **Audio & DirectMusic Fixes**, and permanently resolves the infamous 2005 random map generation crash ("Couldn't find or parse map file"). Memory leaks are stopped, making the game engine cleaner and more stable than ever.
* **9 Hero Slots:** Seamlessly expands the game's control interface from 5 to 9 hero slots, mapped directly to keys 1-9 (special thanks to Upercat's patch).
* **Spotify Integration:** Control your Spotify playback seamlessly directly from the launcher interface, bringing custom soundtracks to your battles without needing to Alt-Tab.
* **Smart Diagnostics:** Automatic crash diagnosis based on engine log files.

**2. Cloud Adventures Manager**
* **Built-in Cloud Catalog:** Browse, download, and update custom community single-player campaigns.
* **Smart Synchronization:** Automatically detects installed maps and notifies you when map-makers release new updates.
* **Zero-Touch Installation:** Download multiple language-filtered maps at once; Avrora automatically extracts and places audio, text, and scenario files in their correct native folders.

**3. Epic Conquests Manager**
* **Large-Scale Campaigns:** Browse and download massive, community-created Conquests directly from the launcher.
* **Simplified Setup:** The system automatically handles complex file placements and integrates the campaigns seamlessly into your game without requiring manual file manipulation.

**4. Integrated Mod Manager**
* **Safe Installation:** Automatically creates a secure, AES-encrypted "Vanilla Backup" of your pristine game files before applying any modifications.
* **Instant Toggle:** Switch between the vanilla base game and massive graphical overhauls with a single click. The app handles all file swaps safely in the background.

**5. Automated Multiplayer Hub**
* **Invisible Installation:** Automatically downloads and installs Radmin VPN silently in the background if missing.
* **Smart Network Routing:** Solves the infamous "invisible lobbies" issue. With one click, the launcher configures the Windows Firewall and forces the VPN interface to Maximum Priority (Metric 1), ensuring direct routing and zero lag.
* **Real-Time Ping Monitor:** A built-in visual indicator displays your Radmin VPN ping directly in the launcher, helping you verify connection stability before starting a match.
* **Auto-Cleanup:** Safely restores default Windows network priorities the exact second you close the launcher.

**6. General Quality of Life**
* Built-in Official User Manual, accessible directly from the launcher.
* Automatic launcher update checking.
* Automatic synchronization between launcher language and game language.
* Multilingual interface: English, Spanish, Italian, Czech.

## Support, Bugs & Feedback
The goal of Avrora is to provide a simple and reliable all-in-one utility that helps players install, configure, troubleshoot, and enjoy the game with minimal effort. 

For any questions, feature requests, or bug reports, please open an issue in the **[GitHub Issues](https://github.com/AlexiusItaly/ImperivmLauncher/issues)** section of this repository. Detail your suggestion, bug, or idea, and I will reply as soon as possible!

**1. Architettura, Patch e Personalizzazione**

* **Gestione DPI Nativa:** Disattiva automaticamente il ridimensionamento di Windows per evitare interfacce sfocate e testi sgranati sui moderni monitor ad alta risoluzione.

Le perdite di memoria vengono arrestate, rendendo il motore di gioco più stabile che mai.
